## Conventions
- `Session` dataclass is the canonical shape (NOT inline dicts) for everything Phase 3.
- Lazy-import optional deps (`datasets`, framework SDKs).
- All metric calculators are pure-Python Tier-1 (sub-1ms target per `docs/performance/budgets.md`).
- LocalDriver uses OpenRouter via the existing provider (no new env wiring).
- Live tests gated by `@pytest.mark.live` and `OPENROUTER_API_KEY`.
- Fixtures: at least one Claude Code JSONL sample (synthesise; don't commit real session contents from `~/.claude/projects/` — anonymise).

## Coordination etiquette
1. Run `uv sync` before starting (Python 3.12).
2. Never edit a file outside your "Owns" column. Lazy-import where you need a stub.
3. Each module's keywords live in `<module>/library.py` with class name `<Module>Keywords`.
4. Memory namespace: `agentguard/phase3/<module>_status` for cross-agent coordination.
