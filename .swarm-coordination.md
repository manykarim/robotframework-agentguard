## Single rule for collapse agents (A, B, C, D)

For every keyword in `docs/proposals/keyword-reduction-table.md` marked
`COLLAPSE`:

1. Add `assertion_operator: AssertionOperator | None = None`,
   `assertion_expected: Any = None`, `message: str | None = None` parameters
   to the existing Get keyword.
2. Wrap the return: `return assert_value(value, assertion_operator,
   assertion_expected, message=message)`.
3. Ensure the Get keyword's return type is **typed** (`-> float`, `-> int`)
   per the exp_11 finding. If the existing return is `Any`, narrow it.
4. **DELETE** the corresponding `Should Be Above` / `Should Be Below` /
   `Should Be Between` / `Should Be Equal To` / `Should Be Zero`
   keyword from the same `library.py`. No shim wrapper.
5. Update existing unit + acceptance tests to use the operator form
   (e.g. `Read Edit Ratio Should Be Above ${s} 4.0` →
   `Read Edit Ratio ${s} >= 4.0`).
6. mypy `--strict` clean before reporting back.

For the resistant cases (`Mann Whitney U Should Show Improvement`, `Hook
Should Block`, `Should Not Call Any Tool`, `Skill Should Pass Security
Scan`, `Tool Sequence Should Match`, `Required Tool Should Have Been
Called With Params`, `Behavioral Report Should Match Baseline`, `Tool
Hit Rate Distribution Should Stochastically Dominate`, `Scenario Drift
Should Not Exceed`): **KEEP unchanged** per the policy in
`docs/ddd/assertion-engine-shared-kernel.md` §6.
